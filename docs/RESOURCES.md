# Curated Engineering Learning Resources & Documentation Hub

A hand-picked selection of industry-standard documentation, interactive tutorials, books, and deep dives to support your growth throughout the internship.

---

## 1. Core Language & Runtime Standards

### JavaScript & TypeScript
- **[MDN Web Docs (JavaScript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)**: The definitive reference for modern ECMAScript specifications, array methods, async/await, and event loops.
- **[JavaScript.info](https://javascript.info/)**: Comprehensive, step-by-step tutorial covering modern JavaScript from fundamentals to advanced closures and prototypes.
- **[Node.js Official Documentation](https://nodejs.org/en/docs/)**: API references for core Node.js modules (`node:fs`, `node:test`, `node:path`, `node:child_process`).
- **[TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)**: Essential guide for static typing, interfaces, generics, and type narrowing.

### Python (Role-Specific)
- **[Real Python](https://realpython.com/)**: Practical, production-grade Python tutorials and best practices.
- **[Python 3 Official Docs](https://docs.python.org/3/)**: Standard library and language reference.

---

## 2. Software Architecture & Clean Code

- **[Refactoring Guru](https://refactoring.guru/)**: Visual and highly intuitive explanations of Gang of Four (GoF) design patterns, SOLID principles, and code smells.
- **[Twelve-Factor App Methodology](https://12factor.net/)**: The gold standard for architecting modern, scalable, cloud-native applications.
- **[Clean Architecture by Robert C. Martin](https://blog.cleancoder.com/)**: Principles of decoupling domain logic from UI and database frameworks.
- **[Google JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html)**: Standards for formatting, variable conventions, and idiomatic coding.

---

## 3. Git & Collaborative Version Control

- **[Pro Git Book (Free)](https://git-scm.com/book/en/v2)**: The complete handbook authored by Scott Chacon and Ben Straub.
- **[Learn Git Branching (Interactive)](https://learngitbranching.js.org/)**: Visual game to master branching, rebasing, cherry-picking, and merge mechanics.
- **[Conventional Commits Specification](https://www.conventionalcommits.org/)**: Semantic commit message conventions for changelog automation and clean history.

---

## 4. Testing & Reliability

- **[Testing Trophy by Kent C. Dodds](https://kentcdodds.com/blog/the-testing-trophy-and-testing-classifications)**: Balance unit, integration, and end-to-end testing effectively.
- **[Node.js Native Test Runner Documentation](https://nodejs.org/api/test.html)**: How to leverage built-in zero-dependency test runner and assertion frameworks.

---

## 5. Developer Tools & Terminal Productivity

- **[Oh My Zsh / PowerShell Core](https://github.com/ohmyzsh/ohmyzsh)**: Modern terminal productivity setups.
- **[VS Code Keybinding Reference](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)**: Multi-cursor editing, command palette navigation, and split-screen shortcuts.
